# ADR-0012: WiX v5 per-user MSI as the installer; MSIX later

## Status

Accepted 2026-11-16 (user chose WiX).

## Context

NoDrive is unpackaged and per-user: no driver, no service, no elevation. The installer must place the AOT exe, add a Start menu entry and an optional autostart value, stop a running engine before upgrading, unregister the sync root on a real uninstall without breaking upgrades, and refuse to remove NoDrive while uploads, deletes or renames are still queued. Inno Setup would also have worked; MSI was preferred for upgrade rules, Apps and features integration and later enterprise deployment. WiX v6 and later (v7 current) fall under the Open Source Maintenance Fee EULA, which targets revenue-generating use ([WiX OSMF](https://docs.firegiant.com/wix/osmf/), [v6.0.0 announcement](https://www.firegiant.com/blog/2025/4/7/wix-v600-available/)); v5.0.2 is the last release before it and is pinned. MSIX needs a signing certificate and package identity that NoDrive does not need.

## Decision

`installer/NoDrive.wxs` builds `NoDrive-x64.msi` with WiX 5.0.2 (`wix build ... -ext WixToolset.UI.wixext`, WixUI_Minimal with the MIT licence) in the `windows` workflow; the MSI and its build log are published as the `NoDrive-installer-win-x64` artifact and under `installer/` on the `ci-binaries` branch. Scope `perUser`, install folder `%LOCALAPPDATA%\Programs\NoDrive`, MajorUpgrade, properties `AUTOSTART` (default 1) and `SUPPRESSLAUNCH`. Custom actions call the engine: `--quit --wait 20` before files change (ignored if no engine runs), `--uninstall` on a final removal only (not on upgrade), launch after install. The installer never touches OneDrive; side by side is the default.

## Consequences

### Positive
Clean upgrades (verified in place with `msiexec`), uninstall that keeps downloaded files and protects unsynced work, no admin prompt.

### Negative
Unsigned MSI/exe may be blocked by Windows Application Control or SmartScreen; a refused uninstall shows a generic Windows Installer error; WiX builds only on Windows (done in CI).

### Revisit when
A signing certificate exists (add signing, maybe MSIX/winget), or WiX 5 stops receiving security fixes.
