# ADR-0010: Full hydration policy by default (supersedes the PROGRESSIVE part of ADR-0007)

## Status

Accepted 2026-11-15. Measured on the user's Windows 11 PC (build 26300.x).

## Context

With PROGRESSIVE, Photos (a packaged app) read small ranges of an online-only JPG and Windows cancelled those reads from the app side between 3 ms and 1.4 s after they started (CANCEL_FETCH_DATA carried the exact read range; our handler only forwarded it). Photos then reported the file as corrupted; Paint and "Always keep on this device" worked. OneDrive opens the same file with a "Downloading file" dialog and then Photos shows it. Fetching the whole file on the first read from the provider side was not fast enough: the Graph URL lookup plus the download exceeded the app's deadline. Windows applies max(app policy, provider policy), so the app side cannot be forced down. Thumbnails: under Full, Explorer did not hydrate files to draw thumbnails (measured: no bandwidth burst; online-only pictures show an icon, downloaded ones a preview).

## Decision

Register `StorageProviderHydrationPolicy.Full` with `AutoDehydrationAllowed`. Windows downloads the whole file on first access, shows its own progress dialog, and apps only see a complete file. The choice is stored in the sync root key value `NoDriveHydration`; a changed value (config `hydrationPolicy`, or env `NODRIVE_HYDRATION`) re-registers once and reapplies Flags 1058. The progressive mode, read-ahead and the Photos workarounds stay in the code behind `hydrationPolicy: progressive`.

## Consequences

### Positive
Photos, Edge, Office and other packaged apps work; behaviour matches OneDrive; the engine needs no range heuristics on the main path; thumbnails do not cause downloads.

### Negative
Large videos download completely before playing; online-only pictures have no preview thumbnail until downloaded (cloud thumbnails are P2); very large files hold the opener for the whole download (progress dialog shown by Windows).

### Revisit when
Windows lets providers declare per-app streaming, or a cloud-thumbnail provider makes Progressive attractive again for media.
