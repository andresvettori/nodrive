# ADR-0011: Settings and activity UI as a local web page served by the engine

## Status

Accepted 2026-11-15 (user chose the web page over WinForms/Avalonia).

## Context

The user wanted a screen reachable from the tray to see what the engine does, view and change settings (including bandwidth limits), and read the guides, in English and Spanish, aware of the PC's region and time zone, and possibly reusable if NoDrive ever targets macOS or Linux. The resident process must stay a Native AOT binary with no UI framework: WinForms/WPF are not AOT/trim compatible and a framework would add tens of MB. Alternatives: a separate on-demand WinForms process (Windows only, JIT, about 40 MB while open), Avalonia (AOT-capable, cross-platform, larger and heavier to maintain).

## Decision

The engine hosts a small `HttpListener` on `http://localhost:<port>` (default 47653, fallback free port) that serves one embedded HTML file (vanilla JS, light and dark theme, inline strings for English and Spanish) and a JSON API (`/api/state`, `/api/activity`, `/api/settings`, `/api/pause`, `/api/autostart`, `/api/signin`, `/api/allow-deletes`, `/api/open-folder`, `/api/switch*`). Dates, times and numbers use `Intl` with the Windows regional culture (read with `GetUserDefaultLocaleName` because the engine runs with invariant globalization) and the browser's time zone; the language follows Windows (`GetUserDefaultUILanguage`) unless overridden. Protection: random per-run token delivered only through the tray (cookie afterwards, HttpOnly, SameSite=Strict), Host header check against DNS rebinding, a custom header plus JSON content type on every write (forces a CORS preflight that is never granted), CSP, no external resources.

## Consequences

### Positive
No UI framework in the resident process (idle memory unchanged); same UI can serve other OSes; fast iteration (HTML only); guides open from the Help tab.

### Negative
Needs a browser tab (not a native window); a stale tab after an engine restart needs reopening (the page says so); the port must be free (fallback implemented).

### Revisit when
A native window is wanted for accessibility or notifications, or when other platforms are started.
